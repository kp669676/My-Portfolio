# Video Editor Portfolio

1. Open this folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension (Ritwick Dey).
3. Right-click index.html > "Open with Live Server".
4. Edit js/projects.js with your name, email and work; save and the page reloads.

Folders: assets/videos (MP4 files), assets/thumbs (images), assets/bg (background loop/image).
Tips: keep MP4s H.264 and under ~50 MB each, or use YouTube/Vimeo links for big files.
Deploy free: drag the folder onto netlify.com/drop, or use GitHub Pages / Vercel.
